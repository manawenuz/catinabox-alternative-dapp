## Two separate deployments

V1 and v1.1 are distinct CDP contracts. The interface defaults to v1.1 but lets the user select either version. Each version has independent position and system state; the app does not migrate positions between them.

## Key behavior differences

| Behavior | v1 | v1.1 |
| --- | --- | --- |
| Yield allocation weight | Position collateral above debt (`deposited - debt`). | Position debt. |
| Yield distribution condition | Excess collateral above 100 wei. | Excess above 100 wei and aggregate system debt greater than zero. |
| Configured idle-fee range | Initialized to 1; admin setter permits up to 75. | Initialized to 1; admin setter permits up to 99. |
| Additional yield-fee term | Adds a debt-to-deposit surcharge. | Uses the configured idle fee without v1's surcharge. |
| Minting fee | No v1.1 minting fee. | Reads a live `mintingFee()` value and can add a two-leg fee to debt. |

The fee and allocation behavior is contract accounting, not a quoted borrower APR. Solidity integer division determines exact amounts. See the detailed formulas and block-stamped settings in the [deployed behavior guide](../../deployed-behavior/).

## Settlement at a high level

Before selected operations, a CDP synchronizes eligible excess collateral and settles accrued points for the affected position. V1 allocates according to collateral above debt; v1.1 allocates according to debt. If the position's auto-repay flag is enabled and accrued owing fits within its debt, settlement can lower debt. Otherwise, accrued owing increases deposited collateral.

This means a preview for one version cannot safely be reused for the other. The app selects the contract first, reads its live values, and projects the corresponding settlement rules before an action.

## Choosing a version

Choose the version where the position exists. A new position is created by using the selected CDP. Compare live state and the contract address before signing; a similar interface label does not mean the underlying deployment or its accounting rules are the same.
